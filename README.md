# KSP_autopilot_Python
This is a school project in which I made an autopilot for Kerbal Space Program that flies a plane and spaceplanes reasonably well. :)

Það þarf að actually installa kRPC moddinu til að geta notað þetta með því að draga það yfir í gamefiles. Það gæti líka þurft að opna serverinn sér ef það virkar ekki. Þetta er allt svaka ez og auðvelt að finna tutorial á netinu.
